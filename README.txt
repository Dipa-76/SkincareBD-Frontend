GLOW & CARE — SKIN CARE BD-INSPIRED FRONTEND DEMO

Run:
1. Extract this ZIP.
2. Open the skincarebd-project folder in VS Code.
3. Open index.html in a browser or use VS Code Live Server.
4. Internet is needed for remote Unsplash images.

Pages: Home, Shop, Product details, Cart, Checkout, About, Contact.

IMPORTANT:
- This is an original practice demo, not the official SKIN CARE BD website.
- Products, prices, images and contact details are placeholders, not verified live inventory.
- Cart is stored in browser localStorage.
- Checkout and contact forms are demo-only; no order, message, payment or personal data is sent to a server.
- Ask your supervisor for the authorized repository/source code and scope before editing a live site.
- Later, replace placeholder product data with API calls (for example fetch()) and use a backend/database for real orders and inventory.
